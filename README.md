# 三体模拟器

一个基于 HTML5 和 JavaScript 实现的多体引力模拟系统

## ✨ 特性

- **零依赖**
- **支持多体**
- **易于交互**
- **含存档系统**
- **配置高度自定义**

## 🚀 开始

执行以下命令后，进入 `three-body` 文件夹，打开 `index.html` 即可

```Shell
git clone https://github.com/Fuslone/three-body.git
```
